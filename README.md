# Preprocessing-Induced Bias Control in Patch-Based Nodule vs. Non-Nodule Classification

Code, per-patch predictions and analysis outputs for the manuscript

> **Preprocessing-Induced Bias Control in Patch-Based Nodule vs. Non-Nodule Classification Using Deep Learning Models.** Muzammil Ur Rehman, Najia Saher, Salman Qadri, Ghulam Gilanie.

The study measures how much of the separability reported for patch-based nodule versus non-nodule classification on LIDC-IDRI is created by the patch extraction procedure itself. In the common recipe, positive patches are cut from a variable annotation bounding box and resized to the network input, while negative patches are cut at a fixed pixel size and are not resampled, and each crop is min-max scaled by its own extremes. This repository implements that recipe and four corrected constructions, a statistics-only baseline that quantifies the separability introduced by extraction, a dose experiment that resamples the positive class alone, a backbone ablation on harder negatives, and the five-fold patient-level evaluation of the corrected protocol with EfficientNetB0 at 224 pixels.

## What is in the repository

| folder | contents |
| --- | --- |
| `src/` | every script behind the manuscript's numbers, tables and figures |
| `scripts/` | shell scripts that run the pipeline in order |
| `results/` | outputs of all 132 training runs as per-patch predictions and run metadata, the cohort census, the patch manifest, the fold lists and every analysis table |
| `figures/` | Figures 1 to 12 as generated by the scripts |
| `tests/` | tests for patient-level leakage, sampling rules and the construction conditions |
| `tools/` | a loader fix for scipy on macOS 27 |

The LIDC-IDRI images, the extraction cache and the trained weights are not included; see [SETUP.md](SETUP.md#what-is-not-shipped).

## Quick start

On macOS with Apple silicon and Python 3.11 (other platforms: [SETUP.md](SETUP.md)):

```
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade "pip<27"
pip install -r requirements.txt
python tools/patch_scipy_macos27.py
python -m pytest -q tests
bash scripts/from_predictions.sh
```

The scipy fix changes nothing unless scipy fails to import, which happens on macOS 27 (SETUP.md, step 3). Without the images, 16 tests run and 7 are skipped ([TEST.md](TEST.md)). The last command recomputes Tables II, III and VI, the pooled metrics with their intervals and Figures 2 and 7 to 12 from the shipped predictions in a few minutes, without the images or a GPU.

```
README.md  SETUP.md  REPRODUCE.md  TRAIN.md  TEST.md  METHODS.md  RESULTS.md  CREDITS.md
CITATION.cff

  check_environment.py      verifies versions, pylidc configuration and data
  census.py                 annotation census from the pylidc database
  extract.py                native-grid tile extraction and negative sampling
  audit_coverage.py         reconciles census, scan log and patch manifest
  consort.py                data accounting per stage and per condition
  cohort_stats.py           cohort statistics quoted in the methods
  arms.py                   construction conditions G0 to G4, dose conditions, reference construction
  folds.py                  patient-level five-fold split, single split and counts per fold
  train.py                  two-phase transfer learning, one run per call
  probe.py                  statistics-only baseline and the extraction gap
  stratify.py               resampling factors and the gap within diameter strata
  dedup_audit.py            exact and perceptual duplicate audit across splits
  analyse.py                per-run metrics and threshold rules
  calibration.py            calibration error and score ranges
  seed_contrast.py          paired comparison of G0, G1 and G2 over three training seeds
  dose.py                   artifact dose-response: baseline curve, network points, fits
  backbones.py              eight backbones on unrestricted and hard negatives, five folds at 224
  headline.py               five-fold pooled results and prevalence-adjusted values
  plotting.py               shared figure helpers
  fig_*.py                  one script per manuscript figure
scripts/
  prepare_data.sh           census, extraction, audits, cohort statistics, folds
  train_all.sh              the twenty-five main training runs
  train_backbones.sh        the 107 runs of the backbone ablation
  analyse.sh                baseline, strata, headline, metrics, calibration, seed contrast, dose, backbones, duplicate audit
  figures.sh                all figures
  run_all.sh                the five scripts above in order
  from_predictions.sh       tables and result figures from the shipped predictions only
tests/
  test_leakage.py           split disjointness, cache content, sampling rules, coverage
tools/
  patch_scipy_macos27.py    restores scipy imports on macOS 27 (SETUP.md, step 3)
results/                    shipped outputs (RESULTS.md)
figures/                    generated figures
cache/                      created by extraction, about 1 GB, not shipped
```

All scripts are run from the repository root as `python src/<script>.py` or `bash scripts/<script>.sh`.
